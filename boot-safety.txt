flame-mainline shim image - safety notes
========================================

This image only ever goes to the boot_a partition. It does not touch
boot_b, vbmeta, dtbo, vendor_boot or any bootloader partition, so the
bootloader itself can never be bricked by flashing it.

Before flashing, back up the current boot images (root shell in Android):

  dd if=/dev/block/by-name/boot_a of=/sdcard/boot_a-stock.img
  dd if=/dev/block/by-name/boot_b of=/sdcard/boot_b-stock.img

Then copy both to a PC:

  adb pull /sdcard/boot_a-stock.img
  adb pull /sdcard/boot_b-stock.img

Safest test - no flash at all (works on some bootloaders, not all):

  fastboot boot out/flame-shim-boot-v4.img

If the bootloader says the command is unknown, flash only boot_a:

  fastboot getvar current-slot          # must print a
  fastboot flash boot_a out/flame-shim-boot-v4.img
  fastboot reboot

No auto-reboot on kernel panic is configured (panic timeout 0), so a
failed boot simply hangs; it will not loop. Hold Power+VolDown to get
back to fastboot (Power+VolUp for recovery).

Restore Android at any time with the backup (fastboot is in the
bootloader and is never affected by this image):

  fastboot flash boot_a boot_a-stock.img

Note: while the shim sits in boot_a, LineageOS recovery is temporarily
unreachable (recovery boots the kernel from the active boot slot). The
bootloader/fastboot is not affected, so keep a PC + USB cable handy and
confirm `fastboot devices` works before flashing.

Never flash boot_b with this image: keeping slot b on the stock ROM is
the built-in fallback if slot a keeps failing.
