flame Debian 13 dual boot - safety notes
========================================

Android 17 lives in slot a and is not touched. All writes go to slot b:

  boot_b          flame-debian-boot_b.img   (stock kernel + flame initramfs)
  vendor_boot_b   vendor_boot.img           (stock copy)
  dtbo_b          dtbo.img                  (stock copy)

Never flash the bootloader partitions (abl, xbl, hyp, tz, devcfg, ...),
vbmeta, or anything ending in _a. That is what keeps the device unbrickable.

Before flashing (from Android, root shell or adb root):

  dd if=/dev/block/by-name/boot_b of=/sdcard/boot_b-stock.img
  dd if=/dev/block/by-name/vendor_boot_b of=/sdcard/vendor_boot_b-stock.img
  dd if=/dev/block/by-name/dtbo_b of=/sdcard/dtbo_b-stock.img

The ROM extracts in this folder (boot.img, vendor_boot.img, dtbo.img) are the
same images and are enough to restore slot b byte for byte.

Switch slots from fastboot:

  fastboot --set-active=a     Android 17 (slot a, untouched)
  fastboot --set-active=b     Debian (slot b)

Recovery is its own 100 MB partition and is never modified:

  fastboot reboot recovery    (needs recovery-stock.img only if it was
                               damaged by something else - not this process)

The Debian boot never auto-reboots: if the rootfs card is missing or broken,
the initramfs stays in a rescue shell on the USB serial gadget. Hold
Power+VolUp/Power+VolDown to leave it and reach recovery/fastboot.

If slot b refuses to boot after flashing, set slot a active again - no
reflash is needed, Android was never modified.
